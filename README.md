# My Rustlings V2

## Overview
This repo will track my progress working through Rustlings, a collection of exercises designed to teach Rust programming fundamentals. 

## Purpose
The goal is to complete all Rustlings exercises on my own without looking up the answers. I do this to increase my proficiency with Rust and get hands on experience.

## Resources
Below are the only 2 resources I am allowing myself to reference while completing the exercises
- "The Rust Programming Language" (aka "The Book") - https://doc.rust-lang.org/book/
- The Brown University fork of "The Book" with modifications by researchers at their Cognitive Engineering Lab - https://rust-book.cs.brown.edu/experiment-intro.html
